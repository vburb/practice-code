# Python Practice Quizes

A collection of Python coding quizes and exercises. Each quiz focuses on a different set of skills — data structures, algorithms, string processing, datetime handling, and more.

## How It Works

- Each quiz lives in its own folder (`q1/`, `q2/`, etc.)
- `quiz.md` has the problem statements, examples, and follow-up questions
- `pN.py` files are individual solutions — one per problem
- `solutions.md` (when present) has reference solutions and key takeaways

## Running

Every solution is a standalone script with a built-in smoke test. Just run it:

```bash
python q1/p1.py
```

## Quizes

| Quiz | Focus | Problems |
|------|-------|----------|
| `q1/` | Sliding windows, streaming data, stateful classes | 5 |
| `q2/` | Regex, scheduling, classification, heaps, tokenization | 10 |

## Topics Covered

- Collections (`defaultdict`, `deque`, `Counter`)
- Sliding window patterns
- Regex and string manipulation
- Interval / scheduling logic
- Basic statistics (mean, std dev, outlier detection)
- Datetime arithmetic
- Heaps and greedy algorithms
- Class design and state management

## Requirements

- Python >= 3.12
- No external dependencies (stdlib only)
